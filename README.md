**Git kommandon som används:**  
1.git add . = lägger till all text som ska uppdateras

**Vad är ett repository?**  
Ett repository är en central punk för att samla filer.  

**Vad är en commit?**  
En commit är en sparningspunkt.  

**Vad är versionshantering?**  
Versionshantering är ett system som sparar filer över tid vilket gör det lättare med bland annat spårbarhet.
